The docs folder is where context goes to die.

Every team keeps the reasoning behind its code somewhere: a Markdown folder in the repo, a Notion space, a few notebooks. The folder goes stale because nobody reads it. The wiki is far from the code and farther from the agents. The notebook is one person's.

Now most teams also have agents working in the same codebase, and they need the same context: what was decided, why, and what the numbers say. They don't need it in a chat window. They need it in a place they can search, read and edit, next to the people who wrote it.

Uberblick is that place. One workspace of documents, on your computer, built MCP first: agents write most of it, and you review and adjust in the browser. Comments sit beside the text they are about. Decisions are records, not paragraphs. Numbers live in the document that explains them.

A document can hold more than prose.

The Markdown you already write, plus the blocks that never survive in a README. Data tables and line charts read records stored inside the document, so when an agent updates the records, the chart updates with them.

Why not use Notion, Obsidian or Jupyter?

Use them for what they are best at: Notion for company-wide and non-engineering content, Obsidian for a personal knowledge base, Jupyter for reproducible analysis. Uberblick takes one idea from each and aims them at a small team of people and agents working on one codebase. Which tool fits your team? has the full comparison.

Where does the web UI use monospace?

Only for text a person would paste somewhere: code, terminal output and ids in Settings. Everything else is set in the UI face.

Mono reads as machine output. Used for labels and timestamps it made the chrome look like a debug overlay and competed with real code blocks.

Install in four commands.

Homebrew on Apple Silicon macOS or Linux x86_64. No account, no server. The fourth command registers the MCP server with Claude Code; use codex for Codex.

Terminal
$ brew install uberblick-ai/tap/uberblick
$ mkdir uberblick-notes && cd uberblick-notes
$ ub workspace create "My Workspace"
$ ub open
Editor at http://127.0.0.1:… Keep this terminal open.

# Second terminal, same directory
$ ub mcp install claude

To share a workspace, run a hub on a computer the team can reach. It is one Docker release; Run a hub walks through it.
