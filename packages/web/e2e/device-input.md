# Manual device input checklist

Use Safari on a real iPhone, iPad and 13-inch MacBook with a disposable document.
Playwright's WebKit covers engine behavior and device-sized layouts; these
checks cover native input it cannot reproduce. This checklist is not a delivery
gate.

| Device | Action | Expected result |
| --- | --- | --- |
| iPhone | Tap a paragraph to show the on-screen keyboard; open the slash menu, then select text and open Link and Comment. Dismiss and reopen the keyboard. | The caret, active field and menu choices remain reachable above the keyboard; long menus scroll internally, and dismissing the keyboard restores the visible area. |
| iPad | In portrait and landscape, repeat the keyboard check with the on-screen keyboard, including Link and Comment fields. | The editor keeps focus, the active input stays visible, and the cards remain usable within the visible area. |
| iPhone and iPad | Long-press prose, adjust the native selection handles, then use the native Copy and Paste menu. | The native selection menu remains usable; selection follows the handles, and pasting inserts the chosen text once without losing the selection or leaving stale editor controls. |
| iPhone and iPad | Enable a Japanese or Chinese keyboard, compose text in prose and a Link or Comment field, choose a candidate, then continue typing. | Candidate selection commits the composed text once; intermediate composition does not prematurely submit a field or choose an editor menu item, and the caret stays at the committed text. |
| MacBook | In Safari, use a Japanese or Chinese input method to compose prose and a Link or Comment field; choose a candidate, continue typing, then undo. | Composition commits once without premature menu activation or field submission; continued typing and undo preserve the text and caret. |
| iPhone and iPad | Tap a table cell, type with the on-screen keyboard, compose text with a Japanese or Chinese keyboard, and use Enter, Shift+Enter and Paste. | The table remains drawn; text commits once in that cell, each cell remains one paragraph, and no formatting controls show at the caret or during composition. |
| iPhone and iPad | Long-press text in a header and body cell and adjust the native selection handles within that cell. Tap Bold, Italic, Strikethrough and Inline code; open External link, cancel and then apply a complete URL. | The formatting popup appears below the range with no Comment control. Tapping preserves the selected words, and only those words receive each mark or link. The native selection and edit menu remain usable. |
| iPhone and iPad | Extend a cell selection with native handles into another cell or out of the table, then collapse it or tap elsewhere. | Cross-cell and outside-table ranges offer no formatting; collapsing or moving away removes the popup. |
| iPhone and iPad | With cell text selected, swipe a wide table sideways until the words leave its visible area, then swipe back. | The popup follows the words, hides while they are clipped by the table container and returns with them. The page never scrolls sideways. |
| iPhone and iPad | Swipe horizontally across a table wider than the document. Tap its last column; with an external keyboard, Tab into an off-screen cell. | The table's own container scrolls, the caret is revealed, and the page and neighboring blocks never widen. |
| iPad and MacBook | With a trackpad, scroll a wide table sideways and move between cells with Tab and arrow keys. In the last cell, press Tab. | The table scrolls internally, cell navigation stays usable, and Tab in the last cell adds one body row. |
| iPad and MacBook | With an external keyboard, Tab and Shift+Tab between filled cells, select text using Shift with an arrow, Home or End, press Escape, then select in another cell. Triple-click one cell and extend past its edge using Shift+Arrow. | Navigation, including Tab's whole-cell text selection, shows no popup. A deliberate one-cell text or triple-click selection shows formatting; Escape closes it without collapsing the range, and a new cell selection can open it. Shift+Arrow into the neighboring cell shows no popup. |
| iPhone and iPad | Tap a table cell, then tap its insertion controls and row menu. Insert a column at either edge, insert a row after the last row, and use Insert row above, Insert row below and Delete row in a body row's menu. | Controls appear without hover, each touch target is at least 44px, each action happens once, every row keeps the same number of cells and the first row remains the only header. Revealing controls does not move cell text or widen the page. |
| iPhone and iPad | Swipe a wide table sideways and tap insertion controls at its first and last column; open the current row's menu while scrolled. Select cell text and open its formatting popup. | All column and row controls remain reachable within the table's scroll container, and row controls do not collide with the gutter plus or selected-text formatting popup. Native text selection and its callout remain usable. |
| MacBook and iPad with an external keyboard | Put the caret in a table cell, press Control+Option+R on Mac or Control+Alt+R on another keyboard, then use arrow keys, Enter and Escape in its row menu. Press Control+Option+T or Control+Alt+T and activate the first insertion button with Enter; on MacBook, Tab between buttons and activate them with Enter or Space. | The row menu targets the caret's row without requiring a context-menu key, Escape returns usable focus, and insertion buttons work without changing Tab's normal cell navigation. Header Insert row above and Delete row stay unavailable. |
| iPhone, iPad and MacBook with an external keyboard | Put the caret in a middle cell and press Control+Alt+Left, Right, Up and Down (Control+Option on Mac) to insert a column before or after the cell, or a row above or below it. Repeat at either column edge, in the last row and in the header row. | Each shortcut inserts once at the caret's column or row, including when the target lies beyond the table's visible area. Header Up inserts nothing; Down creates a body row, and the first row remains the only header. |
| iPhone, iPad and MacBook | Archive the disposable document, then tap or right-click table rows and repeat the table-control shortcuts. | The table stays drawn and selectable, no structural action is offered and no action changes its cells. |
