A fresh workspace holds this document and *Welcome*, and nothing else. Two ways
to fill it.

## Connect an agent

`ub mcp install` wires an MCP client — Claude Code, Codex, Cursor — to this
workspace. The agent then reads and writes these documents directly, one block
at a time, with the same tools that search them.

```sh
ub mcp install
```

## Import what you already have

A command that imports a directory of markdown files is coming. Until it lands,
an agent connected above can write documents from whatever you point it at: a
repository, a folder of notes, a single file.

## Or just write

The editor and every agent are clients of the same document at the same time.
Start typing.
